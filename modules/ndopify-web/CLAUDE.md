# ndopify-web

The public marketing site (port 8082, French UI): a Spring Boot + Thymeleaf app with no database, deployed to Heroku
(`Procfile`, `ndopify-web-main.yml`). Its only call to ndopify-server is `GET /v1/tenants`, to find the tenant; its
calls to action link to Partner Central's public wizards. Its infrastructure is copied from the other web apps (same
class names), minus everything about sign-in: no JWT, no cookie, no session.

## Code Organization

Package `com.wutsi.ndopify.web`:

- `ui/home/` (`/`, `templates/index.html`, people looking for a rental → `{partnerCentralUrl}/find-property`),
  `ui/owner/` (`/owner`, `owner.html`, property owners → `/offer-property`), `ui/agent/` (`/agent`, `agent.html`,
  agents → `/join`). Each controller only builds its link with `ui/layout/PartnerCentralUrls.of(tenant, path)`,
  null (the call to action is left out) when the tenant has no `partnerCentralUrl`.
- `ui/layout/TenantAdvice` — puts the tenant in every page's model as `tenant`. Controllers read it from the model
  (`model.getAttribute("tenant")`), never as a `@ModelAttribute` parameter, which request parameters could bind.
- `service/TenantContext` — the tenant whose `publicPortalUrl` prefixes the request URL (from
  `client/ndopify/NdTenantClient`, a plain `RestTemplate`).
- `config/` — `SecurityConfiguration` permits only `/`, `/agent`, `/owner`, `/assets/**` and `/error` (everything
  else is denied: a new page must be added there), `RestConfiguration`, `ClockConfiguration`.

Static assets in `src/main/resources/public/assets/` (one `main.js`, which only enhances). `src/main/html/` is the
prototype (`index.html`, `louer.html`, `bailleur.html`, `agent.html`, `rechercher.html`, `joindre.html`, `annonce.html` — a listing's public page, with a photo viewer and a "Je suis intéressé(e)" contact popup — + assets),
generated by the `/init-website` command: never serve it, and never delete or "clean up" anything in it.

## Testing Patterns

As Partner Central's (see `modules/ndopify-partner-central/CLAUDE.md`): plain unit tests, no server. A
`<Page>ControllerTest` (`MockMvc` standalone) and a `<Page>TemplateTest` (real Thymeleaf engine) per page, with and
without a `partnerCentralUrl`; `TenantContextTest`, `PartnerCentralUrlsTest`, `NdTenantClientTest`
(`MockRestServiceServer`).
