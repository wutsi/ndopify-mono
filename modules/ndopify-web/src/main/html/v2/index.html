Un agent, pas une liste d'annonces

Quel que soit votre projet, vous avez un seul interlocuteur : un agent vérifié qui travaille pour vous.

  • Un agent vérifié

    Chaque agent a fait vérifier sa pièce d'identité et un compte Mobile Money à son nom avant de recevoir son premier mandat.

  • Un agent de votre secteur

    Votre projet est confié à un agent qui travaille dans les quartiers concernés et qui traite ce type de projet : location, vente ou les deux.

  • Un mandat clair, signé en ligne

    Ce que vous voulez, ce que fait votre agent et sa commission sont écrits dans un mandat que vous signez en ligne.

  • Rien à payer pour commencer

    La commission de votre agent n'est due que si votre projet aboutit grâce à lui, comme le dit votre mandat.

Comment ça marche

  1. Dites-nous votre projet

    Louer, acheter, mettre en location ou vendre : la ville, les quartiers, le type de bien et votre budget ou votre prix.

  2. Un agent l'accepte

    Votre projet est proposé à un agent vérifié de votre secteur. Le premier qui l'accepte devient votre agent ; vous êtes prévenu par e-mail.

  3. Signez votre mandat

    Vous recevez le mandat par e-mail et le signez en ligne, sans vous déplacer.

  4. Votre agent s'en occupe

    Il vous propose des biens ou des clients qui vous correspondent et organise les visites, sur place ou en vidéo.

Vous êtes agent immobilier ?

Recevez des mandats de location et de vente dans vos quartiers, de clients qui ont déjà décrit leur projet.
