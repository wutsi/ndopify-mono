Code envoyé

Consultez l'adresse e-mail de votre compte, puis envoyez /connect suivi du code au bot Ndopify. Il expire dans 15 minutes.

Connexion impossible

  1. Recevez un code par e-mail

    Le code à 6 chiffres arrive à l'adresse e-mail de votre compte et expire dans 15 minutes.

  2. Ouvrez le bot Ndopify

    Le bot s'ouvre dans Telegram : appuyez sur Démarrer s'il le propose.

  3. Envoyez-lui le code

    Dans la conversation, envoyez /connect suivi du code reçu, par exemple /connect 123456. Le bot confirme la connexion.

Le code est envoyé à l'adresse e-mail de votre compte.
